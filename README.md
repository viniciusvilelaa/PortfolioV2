# PortfolioV2
A landing page for my portfolio

Static site — no build step. Open `index.html`, or serve the folder (`python3 -m http.server`).

- `css/nocturne.css` — Nocturne design-system tokens and component classes
- `css/main.css` — page layout
- `js/hero3d.js` — `<hero-3d>` Three.js hero visual (loaded from unpkg)
- `assets/projects/` — drop `natalwave.png` and `finance-app.png` here (16:10) to replace the screenshot placeholders
